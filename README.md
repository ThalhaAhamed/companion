# MeetStream Companion

Companion app and integration utilities for MeetStream.

## Status

This repository is being initialized. Implementation details, setup instructions, and usage examples will be added as the project is built out.

## About MeetStream

MeetStream provides meeting bot infrastructure for joining online meetings, recording calls, generating transcripts, and extracting structured meeting data through developer-friendly APIs.

## Repository Scope

- Companion experience for working with MeetStream meeting data.
- Integration helpers and examples for MeetStream-powered workflows.
- Documentation for setup, development, and deployment as the project matures.
